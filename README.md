# Orbe

Orbe é um personal operating system em desenvolvimento, pensado para reunir
módulos como finanças, treino e hábitos. A direção do projeto é local-first e
offline-first, com versões desktop e mobile.

Este repositório contém apenas o scaffold inicial Flutter. Nenhum módulo ou
armazenamento local foi implementado ainda.

## Plataformas

- Android
- Linux

## Começar

Instale o [Flutter](https://docs.flutter.dev/get-started/install) e execute na
raiz do projeto:

```sh
flutter pub get
flutter run -d linux  # Desktop Linux
flutter run           # dispositivo ou emulador Android disponível
```

Para validar o scaffold:

```sh
flutter analyze
flutter test
```
